# Project instructions

- Write project documentation, commit messages, and GitHub release notes in English.
- Keep the app localized in English and Simplified Chinese.
- Use GitHub CLI (`gh`) for release inspection, creation, uploads, updates, and deletion.
- Keep personal deployment scripts and connection details out of this repository and release packages. The public example library contains only `show-options.sh` and `interactive-demo.sh`.
- Validate release archives and checksums before publishing. Build and packaging must not run user scripts or register schedules.
