# ScriptDeck

[English](README.md) | **简体中文**

一款原生 macOS 应用，用于管理本地脚本、并行运行交互式会话，以及安排后台定时任务。

## 安装

从 [GitHub Releases](https://github.com/curiositycigar/ScriptDeck/releases/latest) 下载最新 DMG，打开后将 **ScriptDeck.app** 拖到 **Applications（应用程序）**。复制完成后推出磁盘映像。也可选择下载 ZIP。

DMG 的 **Extras** 文件夹中包含示例脚本库和文档。请先将 `Extras/ExampleLibrary` 复制到“文稿”等可写文件夹，再添加为工作区。每个下载文件均附带 `.sha256` 校验文件。

- 需要 macOS 13 或更高版本。目前发布的二进制版本支持 Apple Silicon（arm64）。
- 应用使用临时签名，尚未经过 Apple 公证。如果 macOS 阻止打开，请在**系统设置 → 隐私与安全性**中检查并允许打开。
- 请自行安装脚本所需的运行环境，例如 Python 或 Node.js。

## 脚本交互界面

脚本可以通过简单的 Bot 风格 JSON 协议，控制包含文本、可选择列表、按钮、文本/密码输入、文件/目录选择、下拉选项、开关和进度指示器的原生面板。在脚本编辑器中开启**交互界面**，即可在独立执行窗口中切换**交互界面**与**终端日志**，可选的 header/footer 分区可固定顶部说明和底部操作，中间内容自动撑满并滚动，终端隐藏输入可自动弹出原生输入框，支持手动输入或填入钥匙串凭据，无需修改脚本或额外安装 UI 应用。示例 **Interactive UI Demo** 演示虚构文件的浏览和删除，并提供基础组件表单及模拟进度，不修改真实文件。协议及 Shell/Python 示例见 [Interactive script panels](Docs/Workspace/InteractiveUI.md)（英文）。交互界面脚本需手动运行，不能创建计划任务。

新建和导入的 workspace 会自动获得 App 内附的 `AGENTS.md`、`AI-INSTRUCTIONS.md`、`InteractiveUI.md` 和 `library.schema.json`，方便 AI 在无需访问 ScriptDeck 源码仓库的情况下开发脚本。已有同名文件会保留。

## 快速开始

1. 进入**工作空间**，点击**添加 Workspace…**（⌘O），选择附带的 `ExampleLibrary` 文件夹，或自己的脚本目录。
2. 导入脚本（⌘I）、将脚本拖入侧边栏，或创建脚本配置。空目录可以初始化为新的脚本库。
3. 选择脚本，填写参数，点击**运行**（⌘Return）。
4. 每次执行会打开独立窗口。关闭窗口后，可从**首页 → 执行中任务**重新打开并查看已有输出。**⌘J** 可重新打开上次选择的执行窗口。
5. 点击脚本名称旁的星标，将其加入**首页 → 常用脚本**。首页同时展示执行中的手动与定时任务，以及已安排的定时任务；完成结果在**日志**中查看。

应用支持**英语**和**简体中文**，默认跟随系统语言。可以在**设置 → 通用 → 应用语言**中切换，退出并重新打开应用后生效。用户自定义名称、配置值和脚本输出保留原有语言。README 提供中英文版本，其他项目文档使用英文。

## 分享工作区

选择**文件 → 导出工作区包…**生成 `.scriptdeck` 文件，包含已登记的脚本文件、参数定义，以及作为默认值保存的运行表单当前参数。接收方将文件拖到主窗口，或选择**文件 → 导入工作区包…**，再选择新工作区文件夹的创建位置。分享前请检查脚本和参数值。包内不包含钥匙串凭据、日志、定时任务、参数历史或仅作为输入引用的文件。工作区外的路径需要重新选择，接收方也需要安装脚本所需的运行环境和依赖。

## 功能

- 独立 Workspace，支持多级分组、搜索、脚本导入和配置编辑。左侧固定图标导航提供首页、工作空间、定时任务、日志和设置入口；在工作空间页面内切换和管理 Workspace。使用 **⌘F** 聚焦脚本搜索，使用 **⌘N** 新建脚本。
- 支持位置参数、命名参数、布尔开关、文件与文件夹选择，以及显示名称与实际值分离的选项。
- 参数表单填满可用面板宽度，标签列随内容调整，窄面板自动切换为上下排列，必填项使用 `*` 标记；文件和文件夹输入支持**在 Finder 中显示**，点击脚本名称旁的信息图标可弹出脚本详情。
- 编辑按钮左侧的最近参数按钮可回填当前工作区、当前脚本最近 5 组调用参数，重复参数移至最前；记录保存在本机应用偏好设置中，可清空。
- 参数区和终端共用随系统外观变化的主题底色，每次执行拥有可独立调整大小的窗口。
- 脚本配置中的**允许多实例**控制当前工作空间内同一脚本的并行执行，默认关闭，旧配置未指定时也采用单实例。运行中的单实例脚本可直接**查看当前实例**；开启后可**再次运行**，通过实例列表按开始时间和编号查看或停止。限制覆盖首页、工作空间和定时执行；发生冲突的定时执行会跳过当次触发并记入日志。
- 多个任务可同时执行，每个会话拥有独立的交互式终端、状态、运行时长和日志。每个窗口的中断、停止和凭据操作绑定自身会话。
- 基于 macOS `launchd` 的一次性、每日、每周和固定间隔定时任务。可从**定时任务**或脚本运行栏中的定时操作创建。
- 菜单栏入口。关闭窗口后应用继续运行，定时任务也可在退出应用后执行。
- 本地执行历史，支持筛选、分页查看日志、导出和删除，可清除24小时前、七天前或一个自然月前的记录。活动记录可重新打开执行窗口；关闭窗口后任务继续运行并保留输出。
- macOS 钥匙串密码保存、本机脚本关联，以及通过 **⇧⌘K** 向当前执行窗口的交互式会话快捷填入密码。

定时任务保存脚本配置和参数的快照，不接受键盘输入，并防止同一定时任务重叠执行。Mac 必须开机且用户已登录。任务不会唤醒 Mac，也不会在睡眠期间执行；恢复后最多补执行一次错过的任务。暂停任务会取消后续执行，停止当前运行需要单独操作。请在当前执行结束后编辑或删除定时任务。

## 脚本库

每个 Workspace 都是包含 `library.json` 和脚本的文件夹：

```text
MyScripts/
├── library.json
├── library.schema.json
└── scripts/
    └── deploy.sh
```

```json
{
  "$schema": "library.schema.json",
  "version": 1,
  "scripts": [{
    "id": "deploy",
    "name": "部署",
    "group": "部署任务",
    "file": "scripts/deploy.sh",
    "interpreter": "/bin/bash",
    "parameters": [{
      "id": "environment",
      "label": "环境",
      "type": "select",
      "required": true,
      "default": "staging",
      "options": ["staging", "production"]
    }]
  }]
}
```

在参数编辑器中选择**可输入的下拉选择**（JSON：`"type": "editableSelect"`），即可选择预设项或直接输入自定义值。`options` 的配置与 `select` 相同；菜单显示选项名称，选择后向脚本传递实际值。手动输入值和自定义默认值按原样传递，定时任务参数同样支持。原有 `select` 类型仍仅接受预设值。

`file` 和 `cwd` 相对于 Workspace 目录解析；省略 `cwd` 时使用脚本所在目录。支持 Bash、Zsh、Python、Node.js、`direct`（使用 shebang）和可执行文件的绝对路径。参数按配置顺序分别传递。完整字段和参数样式请参阅 [Schema](Resources/library.schema.json) 和[脚本编写指南（英文）](ExampleLibrary/AI-INSTRUCTIONS.md)。

可以直接授权 AI 编程助手访问 Workspace 目录，让它创建、修改和整理脚本及其 `library.json` 配置。可让 AI 参考[脚本编写指南（英文）](ExampleLibrary/AI-INSTRUCTIONS.md)，了解配置格式。

应用会检测外部配置修改。配置无效或存在保存冲突时，会显示提示并保留内存中上一次有效配置。从脚本库外导入脚本时，会将其复制到 `scripts/`；移除脚本配置或 Workspace 登记不会删除原始文件。

日志及其元数据保存在脚本旁的 `logs/<脚本文件名>/` 中。日志创建成功后才会开始执行。删除历史记录需要确认，并会永久删除对应的 `.log` 和 `.json` 文件；正在执行或仍在保存的记录会被跳过。单条删除确认弹窗支持勾选“下次不再提示”，确认删除后生效；批量清空仍需确认。每份日志顶部显示拼接后的执行命令，包括解释器、脚本路径和经过 Shell 引号转义的参数。按键不会单独记录，但脚本输出和回显的输入会进入日志。请避免将密码放入脚本参数或打印密码。

定时任务卡片采用自适应网格，卡片等高，操作区底部对齐。每张卡片都提供执行历史按钮，可快速查看该任务的日志。新日志元数据会保存定时任务 ID；旧记录仅在任务仍保留最近一次执行关联时可识别。此视图中的清除操作仅作用于该任务的筛选结果。

执行历史的“清除”菜单支持清除筛选结果、全部已加载历史，或24小时前、七天前、一个自然月前的记录，以每次执行的开始时间判断。按时间清理覆盖所有已加载工作区，不受筛选条件影响；确认框会显示截止时间和记录数量。日志页按时间倒序展示执行记录。重新打开 App 后，选择记录即可查看对应日志；仍保留执行会话的记录也可重新打开执行窗口。

点击脚本名称旁的钥匙按钮，可将密码保存到 macOS 钥匙串并关联当前脚本。在“设置 → 凭据”中管理已保存的凭据；凭据名称及工作区/脚本关联保存在本机应用偏好设置中，不写入脚本库。一个凭据可关联多个脚本。手动执行脚本时，点击执行窗口的钥匙按钮或按 **⇧⌘K**，选择凭据后点击“填入密码”；已关联的凭据优先显示，可选择填入后立即回车。填入时窗口绑定的原执行会话必须正在运行且已关闭终端输入回显（例如 Bash 的 `read -s`）；后台定时任务不支持交互输入。钥匙串可能请求系统授权。密码直接发送到终端，不经过剪贴板或命令参数；如果脚本主动打印密码，仍会出现在输出和日志中。

停留在**交互界面**时，检测到终端隐藏输入可自动弹出输入框。选择**手动输入**或已保存的凭据，再点击**发送**；关联当前脚本的凭据优先显示，可选择是否附带回车。取消后不会反复弹出，可从顶部提醒的**输入隐藏内容…**重新打开。现有终端密码提示无需修改脚本，也无需添加协议字段。关闭回显只是隐藏输入的信号，不一定代表密码请求。触发条件及完整流程见 [Terminal hidden input and saved credentials](Docs/Workspace/InteractiveUI.md#terminal-hidden-input-and-saved-credentials)（英文）。

定时任务定义和独立辅助程序保存在 `~/Library/Application Support/ScriptDeck/Schedules/`；LaunchAgent 文件保存在 `~/Library/LaunchAgents/com.lucasyou.ScriptDeck.schedule.<ID>.plist`。移动应用不会影响已有定时任务，移动脚本后则需要更新相应任务。

## 构建

使用 Xcode 或带有 Swift 6.3 及以上版本的 Command Line Tools。Swift 依赖版本固定在 `Package.resolved` 中，首次构建需要联网。DMG 打包还需要带有 pip 的 Python 3，首次使用时会将 `Scripts/dmg-requirements.txt` 中固定版本的工具安装到 `.build/dmg-python`。安装窗口布局配置位于 `Scripts/dmg-settings.py`。

```bash
bash package.sh  # 构建、临时签名并生成发布 ZIP 和 DMG
bash test.sh     # 使用临时脚本运行自检
```

输出为 `dist/ScriptDeck.app`、`dist/ScriptDeck-<version>.zip` 和 `dist/ScriptDeck-<version>.dmg`，两种归档均附带 `.sha256` 校验文件。DMG 提供 Applications 快捷方式以便拖拽安装，配套文件放在 Extras 中。发布包包含应用、示例脚本库、中英文 README 和英文维护文档。打包不会运行脚本或安装定时任务。

版本信息以 `Resources/Info.plist` 为准：`CFBundleShortVersionString` 为对外版本号，`CFBundleVersion` 为构建号。发布时手动更新两者，构建不会自动递增。构建时会将此文件复制到应用内，打包时使用对外版本号命名 ZIP 和 DMG。
